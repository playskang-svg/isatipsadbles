## URL 정규화

- `http://`는 `https://`로 1회 리디렉션된다.
- trailing slash URL은 slash 없는 canonical URL로 308 리디렉션된다.
- query parameter가 붙어도 canonical은 parameter 없는 공개 URL이다.
- `www.isatips.adbles.com`은 운영 호스트로 구성되지 않아 중복 페이지를 제공하지 않는다.
