# 💡 네이버 지식iN 답변 & 포스팅 자동 발행·연결 에이전트 매뉴얼

본 문서는 네이버 지식iN 질문을 분석하여 **전문적인 완결형 답변을 제공**하고, 질문에 부합하는 글이 당사 사이트에 없는 경우 **고품질 포스팅을 자동으로 생성·발행한 뒤 공신력 있는 출처 링크로 자연스럽게 연결**하는 `kin-agent`의 실무 운영 지침입니다.

---

## 1. 에이전트 핵심 원칙

1. **답변 등록 버튼은 사람이 누른다 (Human-in-the-Loop)**:
   - 네이버 지식iN은 API 또는 매크로를 통한 무분별한 자동 답변을 운영정책으로 강력히 금지합니다.
   - 적발 시 계정 영구 정지는 물론, 연결된 도메인(`isatips.adbles.com`) 전체가 스팸 도메인으로 분류되어 네이버 검색 자산 전체를 상실할 수 있습니다.
   - 따라서 에이전트는 **초안 생성, 검증, 화면 프리뷰, 클립보드 복사**까지만 전담하고, 최종 등록 버튼 클릭은 사람이 직접 수행합니다.

2. **제휴 직링크 삽입 절대 금지**:
   - 쿠팡 파트너스, 숨고 파트너스, 텐핑 등 제휴 직링크를 지식iN 답변에 삽입하면 네이버 AI 필터에 의해 즉각 삭제 및 감점 처리됩니다.
   - 오직 정보성과 공신력을 갖춘 **자사 가이드 사이트의 정식 아티클 링크 1개**만 자연스러운 출처로 연결합니다.

3. **상투적 인사말 배제 & 결론 우선 완결형 답변**:
   - "안녕하세요 질문자님", "질문 잘 읽었습니다", "도움이 되셨으면 좋겠습니다" 등의 매크로성 문구는 100% 필터링 대상입니다.
   - 첫 1~2문장에서 질문자의 구체적 조건(층수, 짐량, 엘리베이터 여부 등)을 반영한 **구체적 견적 범위와 결론**을 바로 제시합니다.

## 2. CLI 명령어 체계 (`npm run kin`)

모든 작업은 `isatipsadbles` 루트에서 `npm run kin -- <명령어>`로 실행합니다.

```bash
# 1. 일일 카덴스 및 운영 현황 확인
npm run kin -- status

# 2. 실시간 고유입·고채택 타깃 질문 스카우팅 (키워드별 네이버 실시간 검색 링크 제공)
npm run kin -- scout

# 3. 질문 분석 및 기존 포스팅 매칭 검사
npm run kin -- match --q "원룸 이사 비용 1톤 트럭 4층 엘베 없을 때 얼마 나오나요?"

# 3. 신규 포스팅 독립 생성 (필요 시)
npm run kin -- write-post --q "식기세척기 이전설치 비용 및 규격장 복구"

# 4. 지식iN 맞춤 답변 생성
npm run kin -- answer --q "<질문 내용>" --slug "<매칭된 아티클 슬러그>"

# 5. 9대 가드레일 엄격 검증
npm run kin -- check --q "<질문 내용>" --text "<답변 내용>"

# 6. 원클릭 통합 파이프라인 (추천)
# (질문 분석 ➔ 매칭 ➔ 없으면 신규 포스팅 자동생성 ➔ 답변 작성 ➔ 가드레일 검사 ➔ 최종 승인 대기)
npm run kin -- pipeline --q "<질문 내용>" --url "<지식iN 질문 URL>"

# 7. 등록 완료 후 이력 기록 (카덴스 관리 및 중복 방지)
npm run kin -- record --url "<질문 URL>" --slug "<슬러그>" --q "<질문>" --text "<답변>"
```

## 3. 포스팅 부재 시 자동 발행 메커니즘

질문자의 세부 주제(예: 식기세척기 이전설치, 특정 지역의 특수 수리 등)를 다루는 글이 기존 620여 개 아티클 중에 없을 경우:
1. `matcher`가 점수 미달(60점 미만) 또는 특수 품목 누락을 판정합니다.
2. `post-generator`가 즉시 `Article` 규격(H2 섹션, 체크리스트, FAQ, 8분 분량 실전 가이드)에 맞춘 고품질 포스팅을 작성합니다.
3. 생성된 아티클은 `lib/kin-generated-articles.ts`에 영구 등록되며, 사이트 즉시 연동 및 배포 준비가 완료됩니다.
4. 신규 발행된 URL(`https://isatips.adbles.com/articles/<slug>`)이 지식iN 답변의 출처 브릿지로 연결됩니다.
5. 이후 변경사항은 `npm run ship`을 통해 GitHub 푸시 및 Cloudflare 배포로 라이브 반영됩니다.

## 4. 9대 가드레일 검사 기준

| 검사 항목 | 검증 기준 | 위반 시 조치 |
|---|---|---|
| **본문 글자수** | 링크를 제외한 순수 텍스트 300자 이상 | 등록 불가 (추가 보강) |
| **링크 개수** | 답변당 최대 1개 | 2개 이상 시 등록 불가 |
| **도메인 안전성** | 자사 사이트(`isatips.adbles.com`) 한정, 제휴 도메인 배제 | 제휴 링크 포함 시 등록 불가 |
| **질문자 조건 반영** | 층수, 엘리베이터 유무, 짐량 등 질문자의 핵심 조건 언급 | 조건 미반영 시 등록 불가 |
| **상투적 인사말** | "안녕하세요", "채택 부탁드립니다" 등 | 스팸 필터 방지 위해 등록 불가 |
| **일일 카덴스** | 하루 최대 3건 이내 | 초과 시 등록 불가 (익일로 이월) |
| **중복 답변 방지** | 동일 질문 URL 또는 질문 내용 재답변 금지 | 등록 불가 |
| **첫 문장 유사도** | 과거 등록 답변의 첫 문장과 100% 동일 금지 | 질문 맞춤형으로 재작성 |
| **완결성** | 링크를 클릭하지 않아도 질문에 대한 해답이 본문에 완결 | 링크 유도형 낚시 금지 |
